# Installation

This install guide assumes you're installing through Steam. If you're using the DRM free version on Linux you will need to run the game through Proton or a similar compatibility layer.

## Windows

1. Install the game, run it once, then close it.
2. Run awesome_vr-0.1-Windows-Setup.exe and choose **Install**.
3. Point the installer to the game folder if prompted.
5. Start the game from Steam and select "Play AaaaaAAaaaAAAaaAAAAaAAAAA!!! for the Awesome"
6. Select VR in the popup.

## Linux desktop and Steam Frame standalone

The installer requires Python 3.9 or newer and either `kdialog` or `zenity`.

1. Install the game and select Proton in the game's Steam Compatibility settings.
2. Start the game once to create its Proton prefix, then close it.
3. Download `awesome_vr-0.1-Linux-Setup.pyz`. (On Steam Frame you will need to open Desktop from the VR dashboard).
4. In the file manager open the properties of the file `awesome_vr-0.1-Linux-Setup.pyz` navigate to the Permissions tab and check the "Is executable" box.
5. Right-click the installer (click the thumbstick on Steam Frame) and choose **Execute**. Check the game folder shown in Setup. Use **Browse...** to select another installation or locate the folder containing `Awesome.exe`. Then choose Install.
6. Start the game from Steam and select Play AaaaaAAaaaAAAaaAAAAaAAAAA!!! for the Awesome.
7. Select VR in the popup.

## Upgrade or uninstall

Close the game before running the installer.

Uninstall other mods before installing. Setup stops and lists any unexpected files in the game folder.

To upgrade, run the new installer and choose Install. You can install directly over the older mod version. To remove the mod, choose Uninstall. This removes mod files and restores the game to flat only.
